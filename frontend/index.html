USER GUIDE

使用说明

了解输入数据要求、求解流程与部署配置。

01

准备四类数据

全局参数、需求分布、候选仓库和距离数据共同构成一个完整场景。可以直接编辑示例，也可以上传同名 CSV。

02

连接求解服务

点击左下角 API 状态，填写 FastAPI 服务地址。本地开发默认使用 http://127.0.0.1:8000。

03

运行与导出

模型完成后会展示 KPI、成本结构、仓库库存和城市满足情况，并支持将结果导出为 CSV。
